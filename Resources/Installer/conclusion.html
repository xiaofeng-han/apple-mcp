Apple Reminders MCP is installed.

Open Apple Reminders MCP in Applications and allow access to Reminders. Full Disk Access is optional: with it, agents can list everything in Recently Deleted and read images on reminders.

Then register the server with your agents. The command is AppleRemindersMCP.app/Contents/MacOS/AppleRemindersMCP --stdio; the README shows the setup for each client.

Apple Reminders MCP 已安装。

在「应用程序」里打开 Apple Reminders MCP，允许访问提醒事项。完全磁盘访问是可选的：开了之后，agent 能列出「最近删除」里的全部提醒，并读取提醒上的图片。

然后把服务器注册到各个 agent。命令是 AppleRemindersMCP.app/Contents/MacOS/AppleRemindersMCP --stdio，各客户端的写法见 README。

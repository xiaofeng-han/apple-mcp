Apple Notes MCP is installed.

Open Apple Notes MCP in Applications. Under General, give it Full Disk Access (to read your notes) and allow it to control Notes (to upload changes to iCloud and to move and delete notes).

Then set up your agents in the app's AI Assistants tab: it finds Claude Code, Claude, Codex, Grok Build, OpenCode, Gemini CLI and Antigravity, registers the server with each in one click, and installs the ones you are missing. To do it by hand, the command is AppleNotesMCP.app/Contents/MacOS/AppleNotesMCP --stdio; the README shows the setup for each client.

Apple Notes MCP 已安装。

在「应用程序」里打开 Apple Notes MCP，在「通用」里给它完全磁盘访问（用来读取备忘录），并允许它控制「备忘录」（用来把改动上传到 iCloud，以及移动、删除笔记）。

然后在 App 的「AI 助手」标签页配置 agent：它会找出 Claude Code、Claude、Codex、Grok Build、OpenCode、Gemini CLI 和 Antigravity，一键把服务器注册到每一个，没装的也能直接安装。要手动注册的话，命令是 AppleNotesMCP.app/Contents/MacOS/AppleNotesMCP --stdio，各客户端的写法见 README。

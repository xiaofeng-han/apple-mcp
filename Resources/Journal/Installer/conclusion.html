Apple Journal MCP is installed.

Open Apple Journal MCP in Applications. Under General, give it Full Disk Access, which it needs to read and write your journal. It works with Journal 3.0 (macOS 27.2).

Then set up your agents in the app's AI Assistants tab: it finds Claude Code, Claude, Codex, Grok Build, OpenCode, Gemini CLI and Antigravity, registers the server with each in one click, and installs the ones you are missing. To do it by hand, the command is AppleJournalMCP.app/Contents/MacOS/AppleJournalMCP --stdio; the documentation shows the setup for each client.

Apple Journal MCP 已安装。

在「应用程序」里打开 Apple Journal MCP，在「通用」里给它完全磁盘访问，用来读写手记。它支持「手记」3.0（macOS 27.2）。

然后在 App 的「AI 助手」标签页配置 agent：它会找出 Claude Code、Claude、Codex、Grok Build、OpenCode、Gemini CLI 和 Antigravity，一键把服务器注册到每一个，没装的也能直接安装。要手动注册的话，命令是 AppleJournalMCP.app/Contents/MacOS/AppleJournalMCP --stdio，各客户端的写法见文档。

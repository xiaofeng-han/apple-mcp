usage: apple-contacts-mcp contacts duplicates [flags]

Find cards that look like the same person (same name in an account, or --by email_or_phone).

  --account string          Only this account (name or id)
  --by name|email_or_phone  Default name
  --format text|json        Print the answer as text (default) or JSON
  --json json|-             Fields as a JSON object (- reads it from stdin); flags override them
  -h, --help                Show this help

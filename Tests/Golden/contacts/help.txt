apple-contacts-mcp
├── --stdio                     Serve MCP on stdin and stdout (what agents start)
├── --settings                  Open the settings window (also what opening the app does)
├── --self-check                Print a diagnosis
├── --version                   Print the version
├── help [COMMAND…]             This tree, or a command's flags (also --help, -h)
├── setup                       Ask for access to Contacts and for permission to control Contacts (for notes)
├── skill                       Print the SKILL.md that teaches an agent this command line
├── agents
│   ├── list                    Which agents are here and set up (the default)
│   │       [--skill] [--folder DIR]
│   ├── set-up (ID… | --all)    Register the server with them, or install the skill
│   │       [--restart] [--skill] [--folder DIR]
│   └── install ID…             Install them, then set them up
│           [--dry-run] [--restart] [--skill] [--folder DIR]
├── contacts
│   ├── list                    List contacts, sorted as Contacts sorts them, with their ids and versions (the default)
│   │       --group string --smart-list string --account string --type person|company --criteria json
│   │       --limit int --offset int
│   ├── search [QUERY]          Find contacts with all these words anywhere on the card (names, company, phones, emails, addresses, note, …)
│   │       --account string --criteria json --email string --group string --limit int --offset int
│   │       --phone string --smart-list string --type person|company
│   ├── read [ID]               Print contacts in full, with the note, groups, cards and the version update and delete take
│   │       --id string…
│   ├── create                  Create a contact: --first-name, --last-name, --organization, --phones JSON, --note, --photo FILE, …
│   │       --type person|company --prefix string --first-name string --middle-name string --last-name string
│   │       --maiden-name string --suffix string --nickname string --phonetic-first-name string
│   │       --phonetic-middle-name string --phonetic-last-name string --organization string
│   │       --phonetic-organization string --department string --job-title string
│   │       --name-order default|given_first|family_first --note string --phones json --emails json
│   │       --urls json --addresses json --dates json --related-names json --social-profiles json
│   │       --instant-messages json --birthday string --other-birthday json|string --photo string
│   │       --photo-crop int… --ringtone string --text-tone string --emergency-bypass off|calls|texts|both
│   │       --[no-]downtime-allowed --account string --group string… --[no-]wait
│   ├── update ID --version string  Change only the fields given; --no-FIELD clears one, a list replaces the whole list
│   │       --card string --type person|company --prefix string --first-name string --middle-name string
│   │       --last-name string --maiden-name string --suffix string --nickname string
│   │       --phonetic-first-name string --phonetic-middle-name string --phonetic-last-name string
│   │       --organization string --phonetic-organization string --department string --job-title string
│   │       --name-order default|given_first|family_first --note string --phones json --emails json
│   │       --urls json --addresses json --dates json --related-names json --social-profiles json
│   │       --instant-messages json --birthday string --other-birthday json|string --photo string
│   │       --photo-crop int… --ringtone string --text-tone string --emergency-bypass off|calls|texts|both
│   │       --[no-]downtime-allowed --[no-]wait
│   ├── delete ID --version string  Delete a contact on every device (ask the user first); this app keeps a copy for 30 days
│   │       --card string
│   ├── deleted                 List the contacts this app deleted in the last 30 days
│   ├── restore ID              Bring back a contact this app deleted (contacts deleted lists them)
│   ├── photo ID                Save a contact's photo (or --which full / poster) and print where
│   │       --which photo|full|poster --output string
│   ├── duplicates              Find cards that look like the same person (same name in an account, or --by email_or_phone)
│   │       --account string --by name|email_or_phone
│   ├── merge --id string… --version string…  Merge cards into the first (--id A --version VA --id B --version VB …); ask the user first
│   ├── link --id string…       Link cards of the same person into one contact (--id A --id B …)
│   ├── unlink ID               Unlink a card (or, given a contact, all its cards)
│   ├── prefer-name CARD        Make this card give its linked contact the name
│   ├── prefer-photo CARD       Make this card give its linked contact the photo
│   ├── me ID                   Make a contact the My Card (confirm with the user first)
│   ├── changes                 What changed since --since TOKEN; without it, the token to pass next time
│   │       --[no-]include-own --since string
│   ├── import FILE             Import a .vcf file into an account (--account) and group (--group); --duplicates skip|update|keep_both|replace
│   │       --account string --duplicates skip|update|keep_both|replace --group string
│   └── export FILE             Write contacts to a new .vcf file: --id, --group, --query, --my-card, or all
│           --group string --id string… --[no-]my-card --[no-]notes --[no-]photos --query string
│           --version 3.0|2.1
├── groups
│   ├── list                    The groups by account, nested, with their counts, and the smart lists with their rules (the default)
│   ├── members [GROUP]         A group's or smart list's members (--nested adds its nested groups'), and its distribution list
│   │       --[no-]nested
│   ├── create NAME             Create a group (--account, --parent, --member ID…)
│   │       --account string --parent string --member string…
│   ├── rename GROUP NEW_NAME   Rename a group
│   ├── delete GROUP            Delete a group; its contacts stay
│   ├── add GROUP --member string…  Add contacts to a group (--member ID…)
│   ├── remove GROUP --member string…  Take contacts out of a group (--member ID…)
│   ├── nest GROUP --parent string  Put a group inside another (--parent GROUP)
│   ├── unnest GROUP --parent string  Take a group out of another (--parent GROUP)
│   └── distribution GROUP --member string  Choose the email, phone or address a member is reached by in a group (--member ID --email …)
│           --email string --phone string --address string
├── smart-lists
│   ├── create NAME --criteria json  Create a smart list from --criteria JSON (see --help), with --highlight
│   │       --[no-]highlight
│   ├── update SMART_LIST       Change a smart list's name (--new-name), rules (--criteria) or highlight
│   │       --new-name string --criteria json --[no-]highlight
│   └── delete SMART_LIST       Delete a smart list (its contacts stay)
├── accounts
│   ├── list                    The accounts with their counts and the default one, the groups, smart lists and My Card (the default)
│   ├── default ACCOUNT         Make an account the one new contacts go to
│   └── sync [ACCOUNT]          Ask Contacts to sync accounts now (one, or all)
├── settings
│   ├── show                    Contacts' settings (the default)
│   └── set                     Change Contacts' settings: --sort-by, --address-format, --vcard-version, --[no-]vcard-notes, --[no-]vcard-photos, --[no-]private-my-card
│           --address-format string --[no-]private-my-card --sort-by first_name|last_name --[no-]vcard-notes
│           --[no-]vcard-photos --vcard-version 3.0|2.1
└── call TOOL [JSON | -]        Run any tool on a JSON object of its arguments; call alone lists the tools

Every contacts, groups, smart-lists, accounts, settings command also takes --json OBJECT (or --json - for stdin), --format json (the answer as JSON) and --help.
Flags: --no-NAME turns a flag off or clears a field; a flag ending in … repeats.
Output is the tool's JSON answer. Exit status: 1 the request failed (reason on stderr), 2 a wrong command or flag.

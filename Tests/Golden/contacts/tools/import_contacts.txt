Import vCards: Imports a .vcf file (one or more vCards, with notes and photos) into an account and optionally a group. A card with the same name as an existing one in that account is a duplicate: skipped and listed (default), merged into it (update), added anyway (keep_both) or put in its place (replace: the old card is deleted, kept 30 days, and the new one joins its groups and links), as in Contacts' import review.

Input schema: {"additionalProperties":false,"properties":{"account":{"description":"Account (name or id); default Contacts' default account","type":"string"},"duplicates":{"description":"What to do with a card whose name exists already; default skip","enum":["skip","update","keep_both","replace"],"type":"string"},"group":{"description":"Also add the imported contacts to this group (name or id)","type":"string"},"path":{"description":"Absolute path of the .vcf file","type":"string"}},"required":["path"],"type":"object"}

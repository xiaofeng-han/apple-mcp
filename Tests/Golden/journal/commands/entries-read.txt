usage: apple-journal-mcp entries read [ID] [flags]

Print entries in full, the text as Markdown, each with the version entries edit takes. By id, or several (--ids repeats, up to 20).

  ID                  Entry id
  --id string…        Several entries, up to 20 (repeat for more)
  --format text|json  Print the answer as text (default) or JSON
  --json json|-       Fields as a JSON object (- reads it from stdin); flags override them
  -h, --help          Show this help

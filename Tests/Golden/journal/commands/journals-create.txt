usage: apple-journal-mcp journals create NAME [flags]

Create a journal, with --color and --icon.

  NAME            New journal name
  --color string  #RRGGBB, or red, orange, yellow, green, mint, teal, cyan, blue, indigo, purple, pink, brown, gray
  --icon string   An emoji, or an SF Symbol name such as book.closed
  --json json|-   Fields as a JSON object (- reads it from stdin); flags override them
  -h, --help      Show this help

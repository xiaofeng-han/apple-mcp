apple-journal-mcp entries
├── list                        List entries, newest first, with their ids and versions (the default)
│       --journal string --[no-]bookmarked --after string --before string --attachment string… --[no-]deleted
│       --sort newest|oldest|edited --limit int --offset int
├── search [QUERY]              Find entries with all these words: in the text, title, prompt, and attachments' places, songs, transcripts
│       --after string --attachment string… --before string --[no-]bookmarked --[no-]deleted --journal string
│       --limit int --offset int --sort newest|oldest|edited
├── read [ID]                   Print entries in full, the text as Markdown, each with the version entries edit takes
│       --id string…
├── create [MARKDOWN]           Create an entry from Markdown, with --title, --date, --journal, --bookmarked, --attach FILE
│       --attach string… --[no-]bookmarked --date string --journal string --title string
├── edit ID --version string    Change an entry in one go: --title, --body, --replace pairs, --append, --date, --[no-]bookmarked, --journal, --attach, --detach
│       --append string --attach string… --body string --[no-]bookmarked --date string --detach string…
│       --journal string --replace json --title string
├── delete ID --version string  Move an entry to Recently Deleted; --permanently deletes one there for good (ask the user first)
│       --[no-]permanently
├── restore ID                  Bring an entry back from Recently Deleted (entries list --deleted lists them)
├── duplicate ID                Copy an entry with its text, date, journal and attachments
└── export FOLDER               Write entries as Markdown files with their photos, videos and recordings into a new folder
        --after string --before string --[no-]bookmarked --journal string

Every entries command also takes --json OBJECT (or --json - for stdin) and --help.
Flags: --no-NAME turns a flag off; a flag ending in … repeats.

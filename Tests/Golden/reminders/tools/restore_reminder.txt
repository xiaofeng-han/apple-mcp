Restore a deleted reminder: Brings a reminder back from Recently Deleted, with the subtasks deleted along with it. Without list it returns to the list it was deleted from, or the default list.

Input schema: {"additionalProperties":false,"properties":{"id":{"description":"Id from list_deleted","type":"string"},"list":{"description":"List name or id to restore into","type":"string"}},"required":["id"],"type":"object"}
